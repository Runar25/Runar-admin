1. Jak v labu vzniká jedno čtení

  1. Charakter — krátký text „kdo je Rúnar“. Jde jako systémový prompt (model ho bere jako svou roli).
  2. Vstup čtení — co dostane ke každému čtení: jméno runy, co runa nese (klíčová slova z v2/runar-runes.js), stránka runy, jeden obraz a pokyn, jak čtení postavit.
  3. Generátor — čerstvý agent (Opus 5.5), který nezná náš kánon ani tuhle konverzaci; dostane jen body 1 a 2 a vrátí text čtení. API se nevolá.
  4. Měření — délka a opakující se slova spočítá skript; radu, tvrzení o čtenáři, pojistky, klišé a „kterou stránku runy čtení nese“ posoudí slepý soudce (další agent, vidí jen zamíchané texty, ne varianty).
