Úkol, který Code umí udělat sám (úklid souborů, přesun, oprava odkazů — i ve složce `Claude outputs/`), Code udělá a Cowork z toho
vynechá. Nepřipravovat ownerovi text „vlož Coworku“.

**Why:** owner 2026-10-24 na připravený handoff Coworku k úklidu `Claude outputs/`: *„coworka z toho úplně vynecháme. všechno se dělá tady.“*
Cowork se zprávou ze session dosáhnout nedá, takže každý takový handoff jde přes ownera — práce navíc pro něj.

**How to apply:** než navrhneš „předat Coworku“, zeptej se, jestli to neudělá Code. Hranice, které platí dál: Dverg Tarot (`dverg-tarot/`)
je samostatný produkt, Rúnarovy session tam nepracují (DECISIONS 2026-10-21 (1)). Souvisí [[handoff-text-in-code-block]],
[[write-for-owner-not-process]].
