Úkol, rešerši nebo dotaz, který by dřív šel Coworku, piš jako handoff pro **CODE session** (novou nebo jinou lane).
Formát zůstává: code block, první řádek `psáno proti commitu <hash>`, sekce `ZMĚNĚNO:` ([[handoff-text-in-code-block]]).
CODE umí i obsahovou rešerši (web, zdroje, texty) — standard výstupu [[cowork-handoff-quality-bar]] platí dál.

**Why:** KUKY 2026-09-30: *„cowork prý končí nebo co a máš všechno předávat code!“* — aplikace hlásí „Tasks on this computer are
being deprecated… From October 6, you won't be able to start new ones. For new work on this computer, use Claude Code.“
Poslední výstup Coworku (rešerše soukromí OpenAI) převzat do `docs/inbox/2026-09-30-cowork-soukromi-openai.md`.

**How to apply:** nový handoff adresuj „PRO: CODE session“, ne Cowork. Hotové výstupy Coworku, které ještě doběhnou, převezmi do
repa (docs/inbox) a ověř fakta ([[verify-agent-claims-about-code]]). Lanes v CLAUDE.md (Cowork-tune/read/tree) jsou od té chvíle historie.
